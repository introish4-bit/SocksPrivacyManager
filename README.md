# SOCKS Desktop Privacy Manager (Advanced Edition)

A Windows desktop application built with C# WinForms designed to manage SOCKS5, SOCKS4, HTTP, and HTTPS proxy configurations, featuring keep-alive persistent connections, WebRTC leak protection, and a 50+ item User-Agent and hardware device profile generator.

## Features
* Supports SOCKS5, SOCKS4, HTTP, and HTTPS proxies with authentication.
* Always-connected keep-alive state management.
* WebRTC IP leak masking.
* 50+ built-in hardware models and User-Agent fingerprints.
* Application launching rules with non-root IP/site whitelisting.
